# 模块 03 · 两者交汇与扩展

把模块 01（SIMT）和模块 02（脉动）缝到一起。**Tensor Core 就是一个小脉动引擎被塞进了 SIMT 核**——这正是你听方案时"两套词混着出现"的根源。然后简单铺一下多核/多芯片扩展的黑话（够用即可，不深挖）。

> 📦 **封装与存储的物理实现已迁出本模块**：第 02 节"第二层：芯片间"那道缝在物理上怎么做出来（TSV、混合键合、F2F/F2B、CoWoS），以及这套物理在 HBM 与 3D-DRAM 上的落地，见 [模块 07 · 封装与存储的物理实现](../07-封装与存储的物理实现/)。那三节讲的是工艺与器件轴，和本模块的"两种范式怎么交汇"不是同一根轴。

> 🔬 **Tensor Core 的电路版**见 [模块 08 第 02 节](../08-微架构与物理实现/02-算术单元的物理实现·一个FMA由什么门组成.md)：它省钱的机制是把 K 次乘加的对阶、归一化、舍入合并成一次做；**NoC 与多芯片互连的电路版**见 [模块 08 第 05 节](../08-微架构与物理实现/05-互连的物理实现·crossbar-NoC与SerDes.md)（crossbar 的平方律、路由器五级流水、并行 PHY 与 SerDes 的能耗分野）。
