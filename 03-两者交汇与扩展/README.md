# 模块 03 · 两者交汇与扩展

把模块 01（SIMT）和模块 02（脉动）缝到一起。**Tensor Core 就是一个小脉动引擎被塞进了 SIMT 核**——这正是你听方案时"两套词混着出现"的根源。然后简单铺一下多核/多芯片扩展的黑话（够用即可，不深挖）。第 03 节接着第 02 节的"第二层：芯片间"往下挖一层，讲那道缝在物理上怎么做出来（TSV、混合键合、F2F/F2B、CoWoS）；第 04、05 节把这套封装物理落到存储上——HBM 是把纵向和横向同时用到极限的那个产品，而 3D-DRAM 是绕开横向约束的另一条路。

### 03 / 04 / 05 三节怎么分工

| 节 | 讲什么 | 关键约束 |
| --- | --- | --- |
| 03 | 封装的通用物理：TSV、键合、F2F/F2B、中介层、热阻 | 纵向撞散热、横向撞光罩极限与岸线密度 |
| 04 | 这套物理在 HBM 上的落地：C-die / B-die、带宽的两个乘数、cHBM、HBF | 容量 = 密度 × 层数 × 颗数，三个整数都卡住了 |
| 05 | 绕开横向接口的另一条路：把 DRAM 直接叠到逻辑上 | 逻辑放上面供电难、放下面散热难，所以容量做不大 |
