# 模块 01 · SIMT 核的物理实现（GPU / SM / CU）

开会听不懂的词几乎全在这条线上——先解最痛的。核心直觉：GPU 不靠"让单条指令跑得快"取胜，而靠**海量驻留 warp 互相掩盖延迟**。理解了 SIMT "为什么必须显式同步"，回头看模块 02 脉动阵列"为什么反而不用"会一下透。

> 🔬 **想知道这些部件在电路上长什么样**，见 [模块 08 · 微架构与物理实现](../08-微架构与物理实现/)：第 03 节讲寄存器堆与 bank 冲突的 SRAM 电路成因，第 04 节讲 warp 调度器、记分牌与 SASS 控制位的硬件形态（occupancy 的物理定义就在那里）；第 02 节 §4 讲 lane 与寄存器堆的接线——`__shfl` 为什么有代价、矩阵指令的 fragment 布局为什么改不了，答案都在那张接线图上。
