# 模块 30 · 互连：从核到集群

数据在芯片内外要走的每一段路：SM 之间、die 之间、卡之间、机柜之间。第 1 节给出四层互连的地图和"哪种并行住哪一层"的判据；第 2 节往下挖到电路，讲这些连线在硅上是什么、每比特搬多远要花多少能量。
