# 模块 05 · 收敛：术语索引 + 真实芯片对照

把前面所有散点挂成一张网。目标很直接：**对方甩出任何一个词，你立刻知道它挂在哪个模块**。

- [术语索引](./术语表.md)：由脚本从各节末尾的「术语卡」自动生成（每张卡含定义/为什么存在/语境例句三段）。查词入口，不要手工编辑；各节术语卡更新后运行 `python3 _模板/build_index.py` 重新生成。
- [真实芯片对照](./01-真实芯片对照.md)：把全库概念钉到 NVIDIA / 谷歌 TPU / 华为昇腾三块硅片上——全库的验收考卷。
