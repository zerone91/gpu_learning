# GPU 学习笔记库

一份从**计算核心的物理实现**到**软件优化栈**的系统性学习笔记。目标不是从零学 CUDA，而是把开会、看方案、读论文时满天飞的黑话，一个个挂到"它在硬件/软件栈的哪个位置、为什么存在"的地图上，最终能**顺畅对话**。

## 范围界定

- ✅ **要补的**：两种计算范式（SIMT / 脉动阵列）的物理实现 + 自顶向下的软件优化栈 + 往下挖到电路层的微架构（模块 08）+ 往上走到集群规模的系统层（模块 09）。
- ⏭️ **主动跳过**：Roofline 模型、量化、数据格式——这几块已是专家水平，不在本库范围内。（**例外**：低精度格式的*数据通路*问题——块缩放的元数据怎么摆、怎么搬——属于本库范围，在模块 06 第 2 节 §4.6。那是布局问题不是数值问题。）

## 学习计划（六个主线模块 + 四个串线模块）

顺序是精心排过的：**先 SIMT 后脉动**（最痛的词几乎都在 SIMT 线上；懂了"为什么必须同步"再看脉动"为什么反而不用"会一下透）；**硬件（0–3）先于软件（4）**（软件栈本质是"把负载映射到硬件"，不懂目标硬件，优化全是悬空的）；**术语表（5）收尾**（把散点挂成一张网）。模块 06、07、08、09 是后加的四根纵向串线，不占主线顺序，随时可以插进来读——其中 **08 是往下挖得最深的一根**（从架构框图一路挖到标准单元、SRAM 位单元、时钟树和良率账），**09 是往上走得最远的一根**（从一个 kernel 一路走到一万张卡的显存账、通信账和故障账）。

## 怎么用这个库

1. **一个专题一个专题地推进**。每开一节，先在该文件的「这一节要回答的问题」里列下自己听不懂的词，讨论完回填正文。
2. **每节都配「开发者视角」栏**（全库标配）：讲任何硬件特性，都同时回答"开发者/软件从哪儿感知到它"——三通道（① 源码拨盘 ② 编译器回执 ③ Profiler 探针），并注明站在 PyTorch / Triton / CUDA C / SASS 哪一层能摸到的不一样。硬件特性大多不是"写"出来的，是拨盘 + profiler 反推出来的。
3. **每节都配「最新架构落点」栏**（全库标配）：把永恒原理钉到最新硅片上——NVIDIA 主线（Hopper→Blackwell→Blackwell Ultra→路线图）的相关新特性、跨厂商命名对照（NV / AMD CDNA / …）、"另一条路"的最新芯片（TPU / Groq / Cerebras / 昇腾）。**务必标注知识截止日期，路线图未出货项显式标注**。
4. **每节结尾提炼「黑话卡」**，同步登记到 [术语表](./05-收敛-术语表与真实芯片/术语表.md)——术语表不是最后才写，而是从第一节就开始长。
5. **改一处，动两头**：学到某个概念在别的模块以别名出现时，回去补「和其它模块的挂钩」。
6. 新建笔记时复制 [`_模板/笔记模板.md`](./_模板/笔记模板.md)，**写作必须遵守 [`_模板/写作规范.md`](./_模板/写作规范.md)**（术语就地解释、完整句子写作、先机制后比喻、术语卡三段式）。样板见重写后的 [01-02](./01-SIMT核的物理实现/02-warp锁步执行与occupancy.md)。
7. 外部资料（论文、架构白皮书、博客链接）丢进 [`_资源/`](./_资源/)。
