# GPU 学习笔记库

一份从**计算核心的物理实现**到**软件优化栈**的系统性学习笔记。目标不是从零学 CUDA，而是把开会、看方案、读论文时满天飞的黑话，一个个挂到"它在硬件/软件栈的哪个位置、为什么存在"的地图上，最终能**顺畅对话**。

## 范围界定

- ✅ **要补的**：两种计算范式（SIMT / 脉动阵列）的物理实现 + 自顶向下的软件优化栈 + 往下挖到电路层的微架构（模块 13）与存储器件（模块 20）+ 往上走到集群规模的系统层（模块 60）。
- ⏭️ **主动跳过**：Roofline 模型、量化、数据格式——这几块已是专家水平，不在本库范围内。（**例外**：低精度格式的*数据通路*问题——块缩放的元数据怎么摆、怎么搬——属于本库范围，在模块 50 第 2 节 §4.6。那是布局问题不是数值问题。）

## 目录结构

全库分三级：**部 / 模块 / 节**。部是粗粒度的主题分区（目录名以一位数字开头）；模块号是两位数，**十位就是所属的部**，所以"模块 21"一看就知道在第 2 部；节号在模块内从 01 起编，附录用 A1、A2，代码精读用 B1～B4。正文里的交叉引用统一写成"模块 21 第 2 节"或"21-02"。

## 怎么用这个库

1. **一个专题一个专题地推进**。每开一节，先在该文件的「这一节要回答的问题」里列下自己听不懂的词，讨论完回填正文。
2. **每节都配「开发者视角」栏**（全库标配）：讲任何硬件特性，都同时回答"开发者/软件从哪儿感知到它"——三通道（① 源码拨盘 ② 编译器回执 ③ Profiler 探针），并注明站在 PyTorch / Triton / CUDA C / SASS 哪一层能摸到的不一样。硬件特性大多不是"写"出来的，是拨盘 + profiler 反推出来的。
3. **每节都配「最新架构落点」栏**（全库标配）：把永恒原理钉到最新硅片上——NVIDIA 主线（Hopper→Blackwell→Blackwell Ultra→路线图）的相关新特性、跨厂商命名对照（NV / AMD CDNA / …）、"另一条路"的最新芯片（TPU / Groq / Cerebras / 昇腾）。**务必标注知识截止日期，路线图未出货项显式标注**。
4. **每节结尾提炼「黑话卡」**，同步登记到 [术语表](./0-导览/01-真实芯片与术语表/术语表.md)——术语表不是最后才写，而是从第一节就开始长。
5. **改一处，动两头**：学到某个概念在别的模块以别名出现时，回去补「和其它模块的挂钩」。
6. 新建笔记时复制 [`_模板/笔记模板.md`](./_模板/笔记模板.md)，**写作必须遵守 [`_模板/写作规范.md`](./_模板/写作规范.md)**（术语就地解释、完整句子写作、先机制后比喻、术语卡三段式）。样板见重写后的 [10-02](./1-计算硬件/10-SIMT核的物理实现/02-warp锁步执行与occupancy.md)。
7. **配图遵守 [`_模板/配图规范.md`](./_模板/配图规范.md)**：先找自由许可的现成图（Wikimedia Commons）并注明作者、许可与来源页，受版权保护的图只给外链，找不到再自绘 SVG；每张图都要亲眼看过。检索、下载、渲染检查、交稿检查用 [`_模板/figtools.py`](./_模板/figtools.py)。
8. 外部资料（论文、架构白皮书、博客链接）丢进 [`_资源/`](./_资源/)。
