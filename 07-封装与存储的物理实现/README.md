# 模块 07 · 封装与存储的物理实现（纵向串线）

前面的模块按**计算部件**组织知识（SM、脉动阵列、两者交汇、软件栈）；这个模块换一根轴，讲**硅片和存储在物理上怎么造、怎么叠、怎么连**——它是模块 03 第 02 节"多芯片扩展"往下挖的一层，但深度和主题都已经自成一线，所以单独成模块。

定位和模块 06 对称：06 是跟着**数据**纵向串一条线（住哪、怎么搬、怎么摆），07 是跟着**封装与存储器件**纵向串一条线（怎么叠、叠到哪撞墙、撞墙之后往哪拐）。

模块里有两条线，可以分开读：

- **封装线（01～03）**：一条递进的链。先从"封装到底指什么"这一层板级基础讲起、再讲通用的封装物理，再看这套物理在 HBM 这个具体产品上的落地，最后看绕开 HBM 结构约束的另一条路。
- **存储器件基础线（04～08）**：封装线里反复出现"DRAM 电容缩不动""闪存擦写有寿命""PHY 又大又费电"这类结论，但没有打开器件本身。这条线补上这一层：SRAM、DRAM、NAND 闪存三种存储器各自**用什么器件存一个比特、怎么读写、因此带来哪些独有的约束**，以及它们各自**通过什么接口接到系统上**。没有器件背景的读者建议先读这条线，再回头读 02、03。

### 封装线三节怎么分工

| 节 | 讲什么 | 关键约束 |
| --- | --- | --- |
| 01 | 板级基础（裸 die → 基板 / RDL → 倒装 → BGA → SMT）＋通用封装物理：TSV、键合、F2F/F2B、中介层（硅 / RDL / 硅桥）、side-by-side 与 2.5D 的分界、热阻、供电 | 纵向撞散热、横向撞光罩极限与岸线密度 |
| 02 | 这套物理在 HBM 上的落地：C-die / B-die、带宽的两个乘数、cHBM、HBF，以及与 GDDR 颗粒的对照 | 容量 = 密度 × 层数 × 颗数，三个整数都卡住了 |
| 03 | 绕开横向接口的另一条路：把 DRAM 直接叠到逻辑上 | 逻辑放上面供电难、放下面散热难，所以容量做不大 |

### 存储器件基础线五节怎么分工

这条线的划分框架是"三种存储器 ×（单元与阵列、接口）"。SRAM 做在逻辑芯片内部，接口只是存储宏的一组同步引脚，篇幅小，所以和单元合成一节；DRAM 和闪存是独立的芯片，接口各自是一个专门的工程领域，所以单元和接口各占一节。

| 存储器 | 单元与阵列 | 接口 |
| --- | --- | --- |
| SRAM | 04（§3～§7）：6T 单元、稳定性与最低工作电压、存储宏、漏电与软错误、微缩 | 04（§8）：存储宏的同步引脚与时序，独立 SRAM 芯片 |
| DRAM | 05：1T1C 单元、破坏性读出、刷新、row hammer、片内纠错、工艺微缩 | 06：控制器 / DFI / PHY 的分层、DQS 源同步、阻抗校准与端接、训练、DIMM 模组、DDR / LPDDR / GDDR / HBM 对照 |
| NAND 闪存 | 07：浮栅与电荷陷阱、编程 / 读 / 擦除、页 / 块 / plane、一个单元存多位、擦写寿命与各类干扰、3D NAND、纠错 | 08：朝 NAND 一侧的 ONFI / Toggle 接口、控制器与 FTL、寿命的系统账、朝主机一侧的 eMMC / UFS / SATA / NVMe |

| 节 | 这种器件最要紧的一条约束 |
| --- | --- |
| 04 | 一位要六个晶体管，读稳定与可写互相牵制，所以面积大、电压降不下去 |
| 05 | 电荷存在电容上，读一次就破坏、不读也会漏，所以必须回写和刷新，电容也难以缩小 |
| 06 | 几十根并行线各自的延迟不相等，速率越高越必须逐根训练对齐 |
| 07 | 电荷靠高压隧穿进出，氧化层每次都受损，所以只能整块擦、擦写次数有限 |
| 08 | 闪存不能原地覆盖写，必须由控制器做地址映射和垃圾回收，寿命和性能都取决于这一层 |

04 的 §2 是整条基础线的总览，把三种存储器并排放在一张表里对照；只想先建立全貌的读者可以只读那一节。

### 和其它模块的接口

- **模块 03 · 02 节（NoC 与多芯片扩展）**：本模块的上游。那里给的是判据（缝的带宽配不配得上芯片内部的带宽），本模块讲这道缝的物理实现。
- **模块 06 · 01 节（存储层级与搬运指令全图）**：那里讲 HBM 的逻辑与电学组织（通道、bank、行缓冲），本模块讲它的物理形态（为什么能堆 16 层、为什么必须紧挨着计算 die）。两边是同一个器件的两个剖面。
- **模块 08 · 微架构与物理实现**：两处合流——模块 08 第 06 节的功耗墙高度由本模块 01 节算的热阻决定；模块 08 第 08 节的良率账（800 mm² 的 die 良率约五成、切成四块省四成硅）是本模块讲 chiplet 与先进封装的经济学基础。
- **模块 05 · 01 节（真实芯片对照）**：MI300、Hopper / Blackwell、昇腾的封装形态可以按本模块 01 节的两个方向归类。
- **模块 08 · 03 节（片上存储的物理实现）**：和本模块 04 节讲的是同一种器件的两个方向。08-03 从 6T 单元往上搭到寄存器堆和 cache，关心的是它在 GPU 微架构里怎么用；本模块 04 节关心器件本身——稳定性、最低工作电压、漏电、微缩和接口。
- **模块 06 · 03 节（数据进 GPU 之前）**：那里把闪存盘当成一个带宽数字来用（NVMe 盘经 PCIe 到显存）；本模块 07、08 节打开这个盒子，讲这个数字背后的器件和控制器。
