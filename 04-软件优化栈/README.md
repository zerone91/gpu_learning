# 模块 04 · 软件优化栈（自顶向下）

软件栈的本质就是**"把负载映射到硬件"**——所以放在硬件（01–03）之后。整条栈：框架计算图 → 图编译器/IR → 算子/kernel 层 → 运行时/ISA → 硬件。第 04 节「核心映射问题」是**整个学习计划的收束点**，把前面所有硬件概念和软件栈缝死。
