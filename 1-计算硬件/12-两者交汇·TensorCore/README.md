# 模块 12 · 两者交汇：Tensor Core

把模块 10（SIMT）和模块 11（脉动）缝到一起。**Tensor Core 就是一个小脉动引擎被塞进了 SIMT 核**——这正是你听方案时"两套词混着出现"的根源。

> 🔌 **多核、多芯片扩展**原是本模块的第 2 节，现归入 [模块 30 · 互连](../../3-互联/30-互连/)，和互连的物理实现放在一起。

> 🔬 **Tensor Core 的电路版**见 [模块 13 第 02 节](../13-微架构与物理实现/02-算术单元的物理实现·一个FMA由什么门组成.md)：它省钱的机制是把 K 次乘加的对阶、归一化、舍入合并成一次做。
