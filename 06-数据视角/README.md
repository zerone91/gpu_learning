# 模块 06 · 数据视角：存储、搬运与布局（纵向串线）

前面的模块按**部件**组织知识（SM 一章、脉动阵列一章、软件栈一章）；这个模块换一根轴，**跟着数据走**：住在哪（层级的物理切分）、怎么搬（指令与三个搬运引擎）、怎么摆（布局 = 硬件约束下的解）、怎么切（tiling 与布局在 tile 边界相遇）。

定位和模块 05 对称：05 是横向收敛（把概念钉到芯片上），06 是纵向串线（把概念串到数据的一生上）。已有机制在这里只做够自洽的复述并指路原文，篇幅花在**串线**（约束传导链、指令矩阵、引擎半径）和**增量内容**（HBM 通道/行缓冲、L2 slice、paged KV、NZ 分形布局、张量格式家族）上。
